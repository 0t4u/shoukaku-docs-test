    Getting Started

    Warning

    Shoukaku runs on Node versions above 18.0.0 and NPM versions above 7.0.0. Currently, Shoukaku is not tested or verified to run on the Deno runtime or the Bun runtime.

    Shoukaku is a stable, powerful and updated wrapper around Lavalink. It is Discord library agnostic, and can add support for new Discord libraries using connectors.

    Set up Shoukaku

    1. Install Shoukaku using your favorite package manager.
    npm i shipgirlproject/Shoukaku#master
    1. Import the library
    import { Client } from "discord.js";
    import { Shoukaku, Connectors } from "shoukaku";
    1. Configure nodes
    const Nodes = [
        {
            name: "Localhost",
            url: "localhost:6969",
            auth: "re_aoharu", // password
        },
    ];
    1. Initialize the library using one of the connectors.

    Discord.js

    const client = new Client();
    const shoukaku = new Shoukaku(new Connectors.DiscordJS(client), Nodes);

    Eris

    const client = new Client();
    const shoukaku = new Shoukaku(new Connectors.Eris(client), Nodes);

    Oceanic.js

    const client = new Client();
    const shoukaku = new Shoukaku(new Connectors.OceanicJS(client), Nodes);

    Seyfert

    const client = new Client();
    const shoukaku = new Shoukaku(new Connectors.Seyfert(client), Nodes);
    Important

    Shoukaku will never initialized if you don't start her before you call client.login()

    client.on('ready', () => {
        client.shoukaku = new Shoukaku(new Connectors.DiscordJS(client), Nodes);
    });
    1. Handle error events

    Always handle "error" events or your program may crash due to uncaught error

    shoukaku.on("error", (_, error) => console.error(error));

    1. Login to Discord

      client.login("token");
    Tip

    If you want shoukaku to be available on client, then bind it to it

    client.shoukaku = shoukaku;
